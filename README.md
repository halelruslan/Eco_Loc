# EcoLoc Алматы — PWA

Открытая платформа экологической культуры Алматы: карта баков и контейнерных площадок, поиск ближайших точек, AI-сортировщик отходов, эко-калькулятор и квиз.

## Возможности

- Интерактивная карта (Leaflet) с фильтрами по типам контейнеров
- Геолокация и список ближайших баков
- AI-сортировщик на TensorFlow.js (Mobilenet) прямо в браузере
- Двуязычный интерфейс: русский / қазақша
- Тёмная тема
- PWA: установка на домашний экран, офлайн-кэш основных ресурсов

## Запуск локально

Откройте `index.html` через локальный сервер (нужен https или localhost для геолокации и SW):

```bash
# Python
python3 -m http.server 8080

# или npx
npx serve .
```

Затем откройте http://localhost:8080

## Деплой на GitHub Pages

1. Создайте репозиторий (например `ecoloc-almaty`).
2. Загрузите содержимое этой папки в корень репозитория (или в ветку `gh-pages` / папку `docs` — в зависимости от настроек Pages).
3. В настройках репозитория: **Settings → Pages → Source** выберите ветку `main` (или `gh-pages`) и папку `/ (root)`.
4. Через 1–2 минуты сайт будет доступен по адресу:
   `https://<username>.github.io/<repo>/`

### Важно для PWA

- Service Worker и Manifest работают только по **HTTPS** (GitHub Pages даёт HTTPS автоматически).
- После деплоя можно «Установить приложение» из меню браузера (Chrome / Edge / Safari на iOS).
- Иконки находятся в `icons/`.
